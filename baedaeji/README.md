# 배대지

Briq(영국 셀렉트숍)과 **별도**인 구매대행·배송대행 웹 서비스 작업 공간입니다.

고객이 메인 배너의 영국 쇼핑몰에 들어가 상품을 고르고, 이 사이트에서 원화 견적·결제를 하면, 운영자가 영국에서 구매해 한국으로 보내는 모델입니다.

## 한 줄 결론

**사업 자체는 실현 가능**합니다. 다만 “고객이 해외몰 장바구니에 담으면 AI가 그걸 읽고 결제 버튼을 만든다”는 방식은 **브라우저·해외몰 약관 때문에 그대로는 불가능**에 가깝습니다. 같은 목적을 **상품 URL을 이 사이트 장바구니에 담는 방식**으로 바꾸면 MVP가 됩니다.

자세한 분석: [docs/feasibility.md](docs/feasibility.md)  
권장 제품: [docs/product-spec.md](docs/product-spec.md)  
다음에 만들 것: [docs/mvp-backlog.md](docs/mvp-backlog.md)

## 다음에 이어서 하려면

채팅에서 **「배대지」**라고 지정한 뒤 아래 중 하나를 주시면 됩니다.

1. 메인에 넣을 **영국 쇼핑몰 링크 목록** (배너용)
2. 브랜드명·도메인 후보
3. 구매대행만 / 배송대행만 / 둘 다 중 선택
4. MVP 화면(랜딩 + URL 담기 + 견적) 구현 시작
