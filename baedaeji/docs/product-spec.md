# 배대지 제품 스펙 (권장안)

Briq과 분리. 구현은 아직 하지 않음. 합의되면 `baedaeji/apps/` 또는 독립 저장소에서 시작.

## 포지션

영국 쇼핑몰에서 고른 상품을 **한국 고객이 원화로 맡기고**, 운영자가 영국에서 사입·검수·국제배송한다.

- 주력: **구매대행** (URL 장바구니)
- 확장: **배송대행** (영국 창고 주소 안내)
- 비목표: Briq처럼 사입 재고를 카테고리몰로 전시

## 고객 흐름

```
메인 배너에서 영국 몰 클릭 (새 탭)
        ↓
상품 페이지 URL 복사
        ↓
배대지 로그인 → “장바구니에 담기”에 URL + 사이즈/색/수량/메모
        ↓
견적 확인 (GBP, 환율, 수수료, 예상 국제배송, 잠금 시각)
        ↓
원화 결제 (PG / 나중에 네이버페이)
        ↓
마이페이지에서 상태 추적
```

버튼 카피:

- 담기 후: **견적 확인** (결제 아님)
- 견적 동의 후: **결제하기**

## 운영자 흐름

결제 완료 주문이 큐에 쌓임.

표시 필드:

- 고객명, 연락처, 한국 배송지, 개인통관고유부호(권한 있는 운영자만)
- 라인: 스토어, URL, 파싱된 상품명/이미지, 옵션, 수량, 견적 GBP/KRW
- 상태: `paid` → `buying_uk` → `purchased` → `in_warehouse` → `shipped` → `customs` → `delivered` / `cancelled_refund`

운영자는 영국에서 해당 URL을 열고 직접 결제한다. 자동화 로그인은 스펙 밖.

## 메인 배너

`baedaeji/data/store-banners.json` 같은 설정으로 운영자가 링크를 추가.

필드: `id`, `nameKo`, `nameEn`, `href`, `image`, `sort`, `enabled`, `mode` (`purchase` | `forward` | `both`)

## 견적 규칙 (초안, 숫자 확정 전)

- 환율: 수출입은행 GBP `tts` 또는 `deal_bas_r` + 고지된 마진 %
- 잠금: 12시간 (설정 가능)
- 품절 시: 해당 라인 전액 환불. 대체 SKU는 고객 동의 후.
- 국제배송: 초기는 “예상”, 실측 후 추가는 약관에 명시할 때만

## 비기능

- 별도 도메인, 별도 호스팅. briq.kr 경로에 넣지 않음.
- 시크릿은 환경변수. 통관부호는 암호화.
- 모바일 웹 우선. 앱은 나중에.
